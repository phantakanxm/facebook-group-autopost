No. 01 — What it does

A quiet workshop for the marketer who already lives inside Facebook groups.

ไม่ใช่ bot ที่แกล้งเป็นคนอื่น — มันคือมือที่ยาวกว่าของคุณ ที่จำเวลาและจำกลุ่มได้

01

Post to groups you already belong to

ไม่ต้องสร้างบัญชีใหม่ ไม่ต้องสมัคร API โพสต์ไปยังกลุ่มที่คุณเป็นสมาชิกอยู่แล้ว ผ่าน browser เดียวกับที่คุณใช้เปิดเฟซบุ๊กจริง

02

Schedule like a calendar, not a queue

ตั้งเวลาโพสต์ครั้งเดียว หรือ recurring (cron) พร้อม jitter — worker หลังบ้านโพสต์ให้เองพร้อมดีเลย์แบบมนุษย์ระหว่างกลุ่ม

03

Your account, your cookies, your machine

Session cookies เก็บไว้ที่เครื่องคุณเอง ไม่ส่งขึ้น cloud ไม่มีเซิร์ฟเวอร์กลางเห็น ถ้าปิดเครื่อง ระบบก็หยุด คุณควบคุม 100%

No. 02 — Install

Three steps, about ninety seconds.

เนื่องจากแอปยังไม่ได้เซ็นใบรับรอง (unsigned) ระบบปฏิบัติการจะเตือนครั้งแรก — นี่คือเรื่องปกติ กดผ่านได้ปลอดภัย

  1. ดาวน์โหลด .dmg สำหรับ Mac (Apple Silicon)

    กดปุ่ม Download ด้านบน — ไฟล์จะถูกบันทึกลง Downloads โดยอัตโนมัติ ขนาดประมาณ 280 MB

  2. ลาก FB Group Autopost เข้า Applications

    เปิด .dmg ไฟล์ที่ดาวน์โหลดมา — หน้าต่างจะโผล่ขึ้นให้ลากไอคอนเข้าโฟลเดอร์ Applications

  3. คลิกขวา → Open ที่ไอคอนในครั้งแรก

    macOS จะเตือน "unidentified developer" — กด Open ใน dialog ถัดไป ครั้งหลังจากนี้เปิดได้ปกติโดยไม่เตือน

¶
ทำไมต้อง right-click? เพราะ Apple ยังไม่ได้ลงชื่อรับรอง (Developer ID) ให้แอปนี้ — ลายเซ็นดิจิทัลต้นละ $99/ปี ซึ่งตอนนี้ยังไม่ได้ลงทุน การกด right-click → Open เป็น workaround มาตรฐานที่ปลอดภัย

  1. ดาวน์โหลด installer .exe

    เลือก "Windows (.exe)" จากลิสต์ Other platforms — ไฟล์ประมาณ 300 MB

  2. ดับเบิลคลิกเพื่อติดตั้ง

    SmartScreen อาจเตือน "Windows protected your PC" — กด More info → Run anyway

  3. เปิด FB Group Autopost จาก Start Menu

    ติดตั้งอัตโนมัติ ไม่ต้อง admin — ข้อมูลเก็บใน %APPDATA%\FB Group Autopost\

  1. ดาวน์โหลด .AppImage

    เลือก "Linux (.AppImage)" — ไฟล์ประมาณ 300 MB พกพาได้ไม่ต้อง install

  2. ทำให้ execute ได้

    เปิด Terminal: chmod +x FB-Group-Autopost-*.AppImage

  3. ดับเบิลคลิกเปิด

    หน้าต่างแอปจะเด้งขึ้น — ข้อมูลเก็บใน ~/.config/FB Group Autopost/

A word
of honesty

เครื่องมือนี้ขัดกับ Terms of Service ของ Facebook. การ automate browser action ไปยังกลุ่มหลาย ๆ กลุ่มอาจทำให้บัญชีโดนจำกัดหรือระงับ ระบบมีการเลียน behavior แบบมนุษย์และจำกัด campaign ขนาดเล็ก แต่ความเสี่ยงยังมีอยู่จริง

ใช้ด้วยวิจารณญาณ อย่าใช้กับบัญชีหลักที่คุณเสียดาย อย่าโพสต์ spam ที่กลุ่มจริงๆ ไม่ต้องการ
